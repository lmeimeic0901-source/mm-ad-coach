# 美美小黑板形式

用户明确要求“美美小黑板／小黑板讲课”，或给出同类课堂参考并要求保留该形式时读取。主 `SKILL.md` 的小黑板十项硬门优先于所有普通写稿习惯。

## 只走两种路径

### 单人

美美本人完成开头演绎。可以变装、分饰错误家长、用画外学生声或切小窗；喊“上课”后回到美美老师，正文不再频繁切身份。节奏依靠黑板更新、产品拆解、报告特写、实验动作和场景切换，不硬写问答。

### 双人

美美是持续主讲老师，丈夫是课代表、错误家长、参数党或操作员。丈夫至少完整承担一项任务：

- 用 2—5 句汇报一个参数或结构，并说明它回答哪个场景；
- 连续完成一组拆解、换向、清洗、负重或实验，并说出可见结果；
- 在开头完整演出一个错误选择，再由老师接管课堂。

不平均分台词，不句句问答。丈夫说完后，美美只做验收、纠错或翻译成家长判断，不能重复同一卖点。

双人版不是把单人版复制一遍再插入“老公上道具”。开头演绎或至少一个完整大点必须重新安排信息交棒；纯操作任务也要让丈夫说出一条资料中已经明确出现的结果，再由美美翻译成家长判断。不得因为画面看起来合理，新增刹车稳、轮子不晃、没有异响、不卡轮、车架没变形等原稿没有写出的观察。

## 课堂骨架

### 1. 开头演绎

前 15—30 秒完成：

1. 一个具体错误或购买动作；
2. 家长正在经历的具体痛点；
3. 老师指出漏掉的判断；
4. “同学们，上课”或等价切换；
5. 说清今天教大家看什么。

网感集中在开头。正文不靠连续回怼和空泛热词维持节奏。

成稿第一段必须直接写实际演绎和口播。不能以“购买判断锚点”开场，也不能跳过开头直接进入黑板第一点。

### 2. 老师身份持续

上课后以老师连续讲解为主。可以自然使用：

- “同学们，黑板看这儿。”
- “老师当妈以后才知道……”
- “第一题，先别看参数，先看……”
- “这一点给老师记住。”

个人经历也从老师身份说出，不突然退回普通测评旁白。

### 3. 只有 2—3 个黑板大点

每个大点只显示一个短标题。写稿前在内部确认：真实困扰是什么、哪个场景会暴露问题、什么结构／动作／参数能看出差异、当前产品有什么来源明确的证据。最终台词把这些信息连成一段老师口播，不逐项提问和作答。

所有大点共同证明一个购买理由。原稿有四组以上信息时，把常规功能、认证、收纳和加分项压成一个短辅助块或字幕，不新增平级大点。

内部检查链不得露在成稿里。禁止出现“很多家长漏看什么”“这一题的标准”“这一题给老师记住”“产品怎样回答”等模板句式；可以直接说场景、演示证据，再自然落到老师结论。

### 4. 孩子场景桥

用户或品牌要求紧扣孩子时，每个大点连接一次：

`孩子／家庭真实使用场景 → 家长增加的任务 → 选择标准 → 产品事实`

只讲高频使用、夜间、出行、清洁、空间、操作和维护等可确认场景。没有可靠证据时，不补改善鼻炎、皮肤、睡眠、免疫、安全感等结果。

原稿自身含有无来源健康结果时，只改弱程度词仍不够。资料只证明结构、材质或动作，就只讲结构、材质或动作；例如不能把“避免起疹”改成“减少闷疹”，也不能把“不伤脊柱”改成“保护脊柱”。

### 5. 产品作为教具

区分四个时机：产品道具出现、说出品牌名、成为选择标准的答案、用结构／动作／参数／报告完成证明。

专业词和数字先说明回答哪个场景。每个大点口播一个最有用的数字或专业词，其余放字幕或特写。

### 6. 互动预算

正文默认 1—3 次互动，只放在转入第一题、上道具、拆解实验或结尾回收。删除后没有少掉信息或动作的互动直接删。

## Brief 与科普

形式不能替代产品分析。有 Brief 时先分清主卖点、必讲、画面项和舍弃项。主卖点进入黑板大点；必讲辅助项合并成短块。

科普不是标配。只有品牌要求知识感，或观众不理解一个原理就无法接受选择标准时，才保留 1—2 个知识点，按：

`真实困扰 → 通俗原理 → 选择标准 → 产品证据`

科普不能增加稿件外的新事实、健康因果和行业结论。

## 结尾

正文已经分点时，不再复述第一、第二、第三，也不能换成三个并列短句把三个大点再念一遍。结尾最多两句：

1. 一句回到最主要的开头痛点，并带出哪类家庭更需要认真选；
2. 一句只收一个总体购买理由，可以接课代表收道具或“下课”。

结尾不得并列三个功能、三种利益或三个测试结果；正文已经证明过的内容不再换词复述。

写完结尾后，把 2—3 个黑板标题各提取一个核心名词。结尾出现其中两个或以上即不合格，必须删到只剩一个总体判断。例如正文标题是“换向／座舱／安全”，结尾不能再次写“换向、座舱、安全这三件事”，也不能改成“推得省力、坐得舒服、真人承重”继续复述。

## 交付前硬检查

任一项不满足，先内部修稿，不输出半成品：

- 开头是否有错误、痛点、老师纠正和当堂任务；
- 第一段是否是实际可念台词，而不是购买判断或分析框架；
- 是否完成老师身份切换并持续到结尾；
- 是否只有 2—3 个黑板大点；
- 是否只推动一个购买判断；
- 每个大点是否有遗漏、原因、标准和产品证据；
- 双人是否按完整任务交棒；
- 双人是否只是复制单人稿后插入一行动作；
- 内部四步判断是否已经变成自然口播；
- 是否删除“漏看什么／这一题标准／产品回答”式模板句；
- 结尾是否只收一个痛点和一个总体购买理由，没有并列复述三个大点；
- 最终稿前后是否没有“读取 Skill／确保格式／两版均通过”等过程或自我验收说明；
- 是否把普通参数罗列伪装成小黑板；
- 是否把“减少”写成“不再”、把“避免”写成“杜绝”、把“有”写成“独有”；
- 实测台词是否只报告原稿明确写出的结果，没有从画面补出刹车、轮子、异响、卡顿或车架状态；
- 原稿的“被曝／客服说／品牌资料显示／报告显示／我实测”等来源词是否完整保留；
- 结尾是否最多命中一个黑板标题核心名词；
- 用户要两版时是否完整交付两版；
- 是否直接留在当前对话，不自动创建长文档。
