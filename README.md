# MM-广告教练

把产品广告 Brief、大纲或已经写好的脚本，推进成方向明确、购买理由成立、事实边界清楚的广告内容。

它既能从 Brief 带到完整脚本，也能审核成稿；明确要求“美美小黑板”时，可生成单人或双人课堂脚本。

## 安装

```bash
npx -y skills add lmeimeic0901-source/mm-ad-coach -g --all
```

## 使用

安装后可以直接发送材料，不需要先输入 Skill 名：

- 只发 Brief：从广告方向和购买判断开始；
- 只发大纲：审核并推进到下一步；
- 只发完整脚本：按广告教练流程审核；
- 说“按美美小黑板单人版写”：交付单人课堂可拍稿；
- 说“按美美小黑板双人版写”：交付双人课堂可拍稿。

### 豆包使用条件

安装并启用后，新建任务并选择 **工作** 模式，再直接粘贴 Brief、大纲或脚本。豆包“对话／快速”模式目前不会稳定调用自定义 Skill。

## 主要边界

- 没有 Brief 时继续完成当前审核，但不猜品牌必讲和禁讲；
- 数字、成分、认证和推荐区间只保持材料原有强度，不自行推出新的医学、营养、功效或安全结论；
- 小黑板正文只保留 2—3 个黑板大点，结尾不重新复述 1、2、3；
- 不保证爆款、投流、转化或品牌过审；
- 不替代账号定位、医生、律师、监管机构或品牌法务。
