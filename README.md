# MM 广告教练

MM 广告教练陪你从广告 Brief 或初步想法开始，先碰创意，再逐步确认真人素材、大纲和成稿；不是只替你直接写一版。

当前豆包专业版：**v3.3.11**。Codex 专用版尚未按这次版本单独验收；请不要把本次发布当作 Codex 版验收结论。

## 安装

### 一句话命令

在支持 `skills` CLI 的 Agent 环境中运行：

```bash
npx -y skills add lmeimeic0901-source/mm-ad-coach --skill mm-ad-coach -g -y
```

### 让 AI 帮你安装

把这句话发给有 GitHub 读取和安装能力的 Agent：

> 帮我安装 MM 广告教练。请从 GitHub 仓库 `lmeimeic0901-source/mm-ad-coach` 获取 `mm-ad-coach` 最新版，安装到我当前使用的 AI 工具里。安装后请确认已启用；如果当前环境不能执行安装，请明确告诉我，不要只说“已安装”。

### 豆包 ZIP 导入

如果当前豆包环境不能通过 Agent 自动安装，可下载 [豆包专业版安装包](downloads/MM广告教练_豆包专业版_v3.3.11.zip)，在豆包的技能管理中导入。豆包不同端的入口可能不同；本仓库没有验证每个手机型号的具体导入界面。

## 使用

安装后选择「MM广告教练」，再发 Brief、产品资料、内容想法或大纲。默认先给两个有实质区别的创意和示意开头；你选定后，再继续真人素材、大纲、完整脚本与局部修改。若已给定大纲并要求扩写，会沿用已确认内容，不重新从创意菜单开始。

## 范围

- 适合好物分享、合集、科普干货、选购内容和美美小黑板。
- 不负责独立完整成稿审核、单品／横向测评、探店与探厂；这些应使用对应的独立 Skill。
- 不保证一轮定稿、爆款、转化或品牌过审；品牌事实和功效表述仍需按 Brief 及品牌审核确认。

## 安全与隐私

本仓库只发布运行 Skill 所需的公开规则文件与豆包安装 ZIP，不发布学员聊天、私人脚本、内部评测样本或预期答案。
