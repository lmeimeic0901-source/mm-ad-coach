# MM-广告教练

把产品广告 Brief、产品资料、创意方向、大纲或未完成脚本，推进成方向明确、购买理由成立、事实边界清楚的完整广告内容。

它负责广告创作和同一轮反馈，不负责独立完整成稿的审核改稿；后者交给单独的 `MM-广告改稿`。明确要求“美美小黑板”时，可生成单人或双人课堂脚本。

## 安装

```bash
npx -y skills add lmeimeic0901-source/mm-ad-coach -g --all
```

## 使用

安装后可以直接发送材料，不需要先输入 Skill 名：

- 只发 Brief：给出真正不同的创意方向、推荐理由和教练下一步；
- 只发大纲：保留用户锁定内容，补齐为完整可拍稿；
- 发未完成脚本：继续完成当前创作；
- 发完整成稿并要求审核：明确转交 `MM-广告改稿`，不混用两套流程；
- 说“写好物分享／科普选购／强种草”：按对应购买逻辑生成；
- 说“做单测／横测”：区分测试条件、证据层级和结论边界；
- 说“写探店／工厂溯源”：区分现场事实、品牌口径和待核验项目；
- 说“按美美小黑板单人版写”：交付单人课堂可拍稿；
- 说“按美美小黑板双人版写”：交付双人课堂可拍稿。

### 豆包使用条件

安装并启用后，新建任务并选择 **工作** 模式，再直接粘贴 Brief、大纲或脚本。豆包“对话／快速”模式目前不会稳定调用自定义 Skill。

## 主要边界

- 没有完整 Brief 时可以继续创作，但不猜品牌必讲、禁讲和未提供事实；
- Brief 中的功能词只算品牌标称，不等于创作者已经实测成功；
- 用户说“还没拍／没实测”时，创意方向必须写现场核验动作和成功／失败分支；
- 数字、成分、认证和推荐区间只保持材料原有强度，不自行推出新的医学、营养、功效、安全或使用感结论；
- `7.2kg` 不能自动写成“不累／轻松”，`可上飞机`不能自动写成“能进客舱／能放行李架／所有航司都能登”；
- 小黑板正文只保留 2—3 个黑板大点，结尾不重新复述 1、2、3；
- 实质性交付后保留“教练下一步”，追问一个会影响下一稿的真实取舍；
- 不保证爆款、投流、转化或品牌过审；
- 不替代账号定位、医生、律师、监管机构或品牌法务。
